# Navarro Trade — GitHub Pages

Сайт Navarro Trade / Sterling Energy Group. Готовая статическая сборка **без npm, бэкенда и сборщика**.

## Структура
- `index.html` — главная, русский
- `navarro.html`, `dostyk.html`, `almaty.html`, `jetway.html`, `ion.html` — страницы компаний, русский
- `en/` — англоязычные страницы
- `assets/` — изображения, стили, JavaScript
- `.nojekyll` — отключение обработки Jekyll
- `.github/workflows/deploy-pages.yml` — публикация через GitHub Actions
- `404.html` — страница ошибок

Все внутренние ссылки и пути к ресурсам **относительные**. Сайт работает как в корне домена, так и в подпапке вида `https://username.github.io/repository/`.

## Публикация на GitHub Pages (рекомендованный способ)

1. Создайте новый **публичный** репозиторий на GitHub (например, `navarro-trade`).
2. Загрузите **содержимое** этого архива в **корень** ветки `main` — не помещайте содержимое в дополнительную папку `navarro_github_pages`.
3. Откройте в репозитории **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Во вкладке **Actions** дождитесь успешного выполнения `Deploy Navarro Trade to GitHub Pages`. При необходимости запустите workflow вручную (`Run workflow`).
5. Сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/navarro-trade/`. При другом имени репозитория изменится конец URL.

**Альтернатива без Actions:** в `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/(root)` и сохраните. Workflow при этом не требуется.

## Локальная проверка

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Важно
- Форма заявки открывает почтовое приложение с письмом на `info@navarro.kz` (mailto). Для фактической серверной отправки заявок нужна отдельная интеграция.
- Данные и фотографии получены из материалов проекта. Перед публичной публикацией проверьте актуальность характеристик объектов, сертификатов, заявлений о мощности и доступности услуг.
- Оформление — белый/глубокий синий, без золотых элементов. Обозначение `KZ ↔ CN` заменено нейтральными характеристиками направлений.
- Файлы **не публикуют** сайт автоматически, пока не загружены в GitHub и не включён GitHub Pages.
